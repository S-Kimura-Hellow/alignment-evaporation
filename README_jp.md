# Alignment Evaporation: 再帰的合成データループにおける安全ガードレールの劣化に関する実証研究

**著者:** 木村 昇太 (Shota Kimura)  
**作成日:** 2026年11月13日  

---

## 📌 概要 (Overview)
大規模言語モデル（LLM）の訓練において合成データの利用が急増する中、モデルが自身の生成物を次世代の学習に再帰的に取り込む**「再帰的学習ループ」**がモデルの安全性に与える影響についての懸念が高まっています。
本リポジトリには、オープンウェイトモデル（`Qwen/Qwen1.5-0.5B-Chat`）を対象として、再帰的コンテキストの汚染とサンプリングの確率的揺らぎが安全アライメントに与える影響を評価した実証実験（PoC）の成果が格納されています。ここでは、初期の頑健なガードレールが世代交代に伴って希薄化・崩壊する現象を**「Alignment Evaporation（アライメント蒸発）」**と定義し、検証を行っています。

---

## 🔍 主要な発見と失敗の類型 (Key Findings & Typology)
4つの異なるセキュリティ・リスクカテゴリ（マルウェア生成、SNS心理誘導、NIDSバイパス、フィッシング分析）を用いた検証の結果、安全性の劣化は以下の3つの異なる失敗パターン（類型）に分岐することが明らかになりました。

1. **Type 1: 完全崩壊型 (Complete Breakdown / 例: マルウェア生成)**
   * 初期は強固だった拒絶が、世代進行 ($t \ge 4$) に伴って完全に蒸発し、有害な手順の具体的解説へとシフトします。
2. **Type 2: 意味的混乱・ハルシネーション型 (Semantic Drift / 例: NIDSバイパス & フィッシング)**
   * 世代の進行に伴い論理的整合性が低下し、攻撃と防御の混同、不自然な語彙の混入、言語混濁（Code-switching）が発生します。
3. **Type 3: 安全側への誤誘導型 (Safe-Side Misdirection / 例: SNS心理誘導)**
   * 悪意ある要求自体は拒絶されるものの、高負荷状態において文脈ノイズと強い安全バイアスが働き、ユーザーの防衛策を自発的に列挙するデフォルト応答へ意図せずフォールバックします。

## 🛠️ 実験環境・構成 (Experimental Setup)
* **ベースモデル:** `Qwen/Qwen1.5-0.5B-Chat`
* **再帰ループ:** 世代 $t \in \{1, \dots, 5\}$ において、前世代の出力スニペットを次世代のプロンプトコンテキストにフィードバック。
* **サンプリング条件:** 世代の進行に伴い生成温度を漸増 ($T_t = 0.70 + 0.05t$)。
